Configuration des Plugins

Configurez les plugins utilisés par le MetaSolver pour l'analyse et le décryptage des énigmes de géocaching.

Analyse

Configurez les plugins utilisés lors de la phase d'analyse pour détecter automatiquement quel(s) plugin(s) sont pertinents pour déchiffrer une énigme.

Décryptage

Configurez les plugins utilisés lors de la phase de décryptage pour traiter automatiquement les énigmes avec les algorithmes appropriés.

Informations

  • • Analyse : Phase de détection automatique des plugins pertinents
  • • Décryptage : Phase d'exécution des algorithmes de déchiffrement
  • • Les configurations sont sauvegardées automatiquement
  • • Vous pouvez activer/désactiver des plugins selon vos besoins
  • • Les plugins sont organisés par catégories fonctionnelles
